# Report-Backed Customer Attrition Comparison

Separate comparison dashboard built only from the Sep 21, 2026 1:11 PM MDT FieldRoutes "All Time Customer List" report export.

- Eligibility: present in the report's "Has Completed Initial Service" population.
- One customer per Customer ID.
- Cohort date: earliest Initial Service across all report rows for that customer.
- Status: report Customer Status snapshot.
- Public data is aggregate-only. No customer-level fields or credentials are published.

This is intentionally separate from the API-backed customer attrition dashboard.
